# Agente de Atendimento para Plataforma Pedagógica (DIO)

Este projeto define a estrutura, diretrizes e prompts para a criação de um **Agente de Inteligência Artificial voltado para o atendimento e suporte pedagógico** em plataformas educacionais (inspirado no ecossistema da DIO - Digital Innovation One).

---

## 🎯 Objetivo do Projeto
Fornecer um assistente virtual inteligente capaz de auxiliar estudantes em sua jornada de aprendizado, tirando dúvidas sobre conteúdos técnicos, rotas de estudo, desafios de código e suporte geral na plataforma pedagógica.

---

## 📂 Estrutura do Arquivo Principal
O arquivo principal [`agente_atendimento_plataforma_pedagogica.md`](agente_atendimento_plataforma_pedagogica.md) contém:
* **Persona e Tom de Voz:** Definição de como o agente deve se comunicar com os alunos (empático, objetivo, técnico e motivador).
* **Diretrizes de Atendimento:** Regras de conduta para suporte a dúvidas de programação, orientações de carreira e resolução de problemas na plataforma.
* **Prompts e Contexto:** Instruções base para configuração do LLM ou agente conversacional.
